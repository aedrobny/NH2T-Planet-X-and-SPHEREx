What are you tuning into?

Infrared light is invisible to human eyes. Different wavelength ranges reveal different features of the same sky: stars, cooler objects, warm dust, and molecular emission. This viewer is locked to D4 so every target is examined with the same infrared detector.

Reading the images

Each frame is an actual SPHEREx observation patch. The image stretch changes visibility, not the underlying measurements. Green, orange, and magenta markers are investigation aids—not confirmed moving-object detections. Every frame uses D4. The image sequence shows separate observations, not continuous video from the telescope.
